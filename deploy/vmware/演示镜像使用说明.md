# EIMS VMware 演示镜像 — 制作与使用说明

适用：**Ubuntu 22.04** + **VMware Workstation** + **仅主机 (Host-Only)** 网络  
固定访问地址：**http://192.168.56.10**

---

## 一、你需要准备

| 项目 | 要求 |
|------|------|
| 宿主机 | Windows 10/11，内存 ≥ 8GB |
| VMware | Workstation Pro 16+（制作镜像）或 Player（仅导入） |
| Ubuntu ISO | [Ubuntu 22.04 Desktop 或 Server](https://ubuntu.com/download) |
| 本项目源码 | 含 `eims-backend`、`eims-frontend` |

---

## 二、制作镜像（Workstation Pro）

### 1. 新建虚拟机

1. **文件 → 新建虚拟机 → 典型**
2. 稍后安装操作系统 → **Linux / Ubuntu 64 位**
3. 名称：`EIMS-Demo`
4. 磁盘：**40 GB**，单个文件
5. **自定义硬件**：
   - 内存：**4096 MB**
   - 处理器：**2 核**
   - 网络：**仅主机模式 (Host-Only)** → 选 **VMnet1**
   - CD/DVD：挂载 Ubuntu 22.04 ISO

### 2. 配置 VMware 仅主机网段

1. **编辑 → 虚拟网络编辑器**
2. 选中 **VMnet1 (Host-Only)**
3. 子网 IP 设为：`192.168.56.0`，子网掩码 `255.255.255.0`
4. 勾选 **使用本地 DHCP**（可选；脚本会设静态 IP）

### 3. 安装 Ubuntu

- 主机名：`eims-demo`
- 用户名：`eims`（或任意）
- 勾选 **Install OpenSSH server**
- 安装完成后重启

### 4. 启用共享文件夹（推荐，方便传文件）

虚拟机**关机**后：

1. **虚拟机 → 设置 → 选项 → 共享文件夹**
2. **总是启用** → 添加 Windows 上的 `project` 目录
3. 共享名例如：`project`

Ubuntu 内挂载路径一般为：

```text
/mnt/hgfs/project
```

若目录为空，在 Ubuntu 安装 **VMware Tools**（菜单：虚拟机 → 安装 VMware Tools），或：

```bash
sudo apt install -y open-vm-tools open-vm-tools-desktop
sudo reboot
```

### 5. 在 Windows 上先打包（推荐）

在 `project` 目录下执行：

```bash
cd eims-backend
mvn clean package -DskipTests

cd ../eims-frontend
npm install
npm run build
```

### 6. 在虚拟机内一键安装

```bash
# 进入共享的项目目录（路径按实际调整）
cd /mnt/hgfs/project/deploy/vmware
chmod +x install-eims-vm.sh
sudo bash install-eims-vm.sh /mnt/hgfs/project
```

脚本会自动完成：

- 安装 JDK 8、MySQL、Nginx
- 设置 IP 为 `192.168.56.10`
- 导入数据库
- 部署 JAR 与前端
- 配置开机自启

### 7. 验证

Windows 浏览器打开：**http://192.168.56.10**

| 账号 | 密码 |
|------|------|
| admin | Admin@123456 |

### 8. 导出 OVA

1. **关机**（不要挂起）
2. **文件 → 导出为 OVF...**
3. 格式选 **OVA（单文件）**
4. 保存为 `EIMS-Demo.ova`

## 三、使用镜像（导入方）

### 环境要求

- VMware Workstation Player 16+ 或 Pro
- 电脑内存 ≥ 8GB
- 硬盘空余 ≥ 20GB

### 步骤

1. 安装 VMware Workstation Player
2. **文件 → 打开** → 选择 `EIMS-Demo.ova`
3. 导入完成后**开机**
4. 等待 1～2 分钟（MySQL、后端启动）
5. 浏览器访问：**http://192.168.56.10**
6. 登录：`admin` / `Admin@123456`

### 访问不了时

| 现象 | 处理 |
|------|------|
| 页面打不开 | 确认虚拟机已开机；Player 里网络设为 **仅主机** |
| IP 不是 192.168.56.10 | 虚拟机终端执行 `ip a`，用显示的 IP 访问 |
| 后端未启动 | `sudo systemctl status eims`，`sudo journalctl -u eims -n 30` |
| Windows  ping 不通 | 确认 VMware 虚拟网络编辑器中 VMnet1 已启用 |

## 四、常用运维命令（虚拟机内）

```bash
# 查看服务状态
sudo systemctl status eims nginx mysql

# 重启应用
sudo systemctl restart eims

# 查看后端日志
sudo journalctl -u eims -f

# 查看 IP
ip a
```

```text
/opt/eims/

└── frontend/           # 前端静态文件

/etc/systemd/system/eims.service
/etc/nginx/sites-available/eims
```
